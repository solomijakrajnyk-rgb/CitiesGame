Cities Game

Графічна гра «Міста» на Java з використанням Swing та AWT.

Опис

У грі користувач називає місто з доступної колекції. Комп’ютер відповідає містом, яке починається з останньої літери міста користувача.

Якщо місто закінчується на м’який або твердий знак, ці знаки не враховуються при визначенні останньої літери.

Літера «й» враховується як остання літера міста.

Повторно використовувати вже названі міста не можна.

Гравець може завершити гру командою «здаюсь».

Технології

* Java 21
* Gradle
* Swing
* AWT
* JUnit 5

Запуск

Для запуску гри з Terminal:

./gradlew :app:run

Тестування

Для запуску автоматичних тестів:

./gradlew :app:test

Для повної перевірки та збірки проєкту:

./gradlew clean build

Структура

* AppLauncher — точка входу в програму.
* game — логіка гри та колекція міст.
* ui — графічний інтерфейс.
* CityGameTest — автоматичні тести логіки гри.
* cities-icon.png — іконка програми.
